Char Manage Help

Character Management Commands:
//goto_char_menu <name> - Teleporta voce ate o jogador.
//recall_char_menu <name> - Puxa o jogador ate voce.
//kick_menu <name> - Desconecta o jogador.
//kill_menu <name> - Mata o jogador.
//ban_menu <name> - Bane a conta do jogador.
//unban_menu <name> - Desbane a conta do jogador.
//changelvl <name> -100 - Bane o personagem.
//changelvl <name> 0 - Desbane o personagem.
//jail <name> - Envia o jogador para a prisao.
//unjail <name> - Liberta o jogador da prisao.
//recall_party_menu <name> - Puxa toda a party do jogador.
//recall_clan_menu <name> - Puxa todo o cla do jogador.
//teleport_character_to_menu <name> <x> <y> <z> - Envia o jogador para coordenadas ou vilas predefinidas.
