1) Create a profile To create a profile you need to click on the button "Start Recording".Next, you apply the necessary spells to yourself at the Buffet NPC after the end of the set of buffs press the button "Conservation" and select the profile number from 1st to 4th. 2) Use a saved profile Once you have created a profile, to use the created profile you just need to click on the profile in which you saved your set of spells - it will be imposed on you automatically. 3) Overwrite a saved profile To overwrite the profile - you need to have no spells on your character, click "Start Recording" and then "Save". After these steps, the profile will be deleted.
